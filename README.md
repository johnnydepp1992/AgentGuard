# AgentGuard 🛡️

AgentGuard protects crypto wallets managed by autonomous AI agents. By deploying this smart contract on the NEAR blockchain, users can set strict financial boundaries for their AI assistants.

## Features
- Transaction Limits: Prevents the AI from spending more than a set amount in a single transaction.
- Daily Limits: Caps the total amount the AI can spend in 24 hours.
- Whitelist Guard: Freezes transactions sent to unknown addresses until a human approves them.

Built for the NEAR Hackathon 2026.
